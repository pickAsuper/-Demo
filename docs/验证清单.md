## 真实数据库集成测试

`npm test` 启动隔离的 PostgreSQL 实例，覆盖：迁移幂等、商品读取、计价与运费、扣库存、同一订单并发重试、最后一件商品并发抢购、库存不足回滚、数据库中途失败回滚、设备订单隔离、非法输入、订单价格快照，以及数据库进程重启后的持久化。测试结束删除临时库。

## Electron 功能与视觉验证

`npm run test:desktop` 使用隔离的 PostgreSQL、API 与 Electron 用户数据目录：

- 首屏：侧栏、横幅、分类、商品图片、价格与购物车按钮可见，无横向溢出。
- 商品：分类切换、搜索、无结果、清除搜索、价格排序、详情弹窗与关闭。
- 购物车：空状态、加入商品、数量加减、移除、重载后持久化。
- 结算：收货信息、运费、提交、成功提示、查看订单与金额。
- 学习指南：开发到发布的五个步骤。
- 设置：读取地址、保存地址、连接失败与重新连接。
- 最小桌面窗口：920 × 680 检查导航、商品与结算布局。
- 异常探索：无搜索结果；库存上限；服务断开；禁止任意 IPC 路由。

截图需要单独检查：截断、遮挡、文字可读性、商品插画比例、弹窗滚动和主按钮。自动化断言不能代替视觉检查。
